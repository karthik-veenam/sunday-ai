Hear the actual audio around each trigger. The default threshold is 0.50. Compare lower and higher thresholds, then label whether “Sunday” is audible. Your choices here inspect saved tests; they do not change the live detector.

How these clips are selected

These are candidate false activations from recordings historically labelled negative. Each excerpt includes up to 2 seconds before and 1 second after the trigger. “Longer context” gives up to 5 seconds before and 2 seconds after. The timestamp marks the end of the model’s 80 ms frame, so listen before the marker too.

Default view: continuous household negatives, excluding the first 2.5 seconds of each file. Separate views include the provisional family recording, short snippets, and old extracted errors. Short snippets use the same added silence as the test. Clips may overlap because the test uses a 2-second cooldown.

Scores are uncalibrated model outputs. Reviews are saved by source and trigger position. A different threshold may select a different position around the same sound. Finding “Sunday” means the negative label needs checking; no training data is automatically relabelled.
