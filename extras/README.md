# Optional supporting tools

- `prompt-editor/`: local system-prompt editor and service reference.
- `dev-mode/`: developer bridge/display/speech helpers, with local authentication required.
- `interaction-debug/`: recent-turn timing/decision collector and frontend card.
- `feelings-dashboard/`: emotional-state UI/publishing helpers.
- `clip-review/`: wake recording review/denoise routes; no private audio or datasets included.
- `firetv-lan/`: local Fire TV helpers where available.

These are optional and often reference the existing `/home/djpi/...` layout. Runtime tokens, settings, recordings and cached responses are excluded. Review each entry point before use; publication helpers can alter dashboards when explicitly executed.
